A few things to know.

Is TurfDeck free?

Yes. The public beta is free to use, with no activation key or trial expiration. Donations are optional.

Where do downloads and updates come from?

The signed Windows releases are hosted on GitHub. The Download buttons use the latest available Setup installer when it can be checked, or take you to the latest release page.

Where is my course data kept?

TurfDeck keeps your records locally on your computer. Make regular backups. Posting on the public feedback board shares only the text and files you choose to post there.

Can I suggest a feature without a GitHub account?

Yes—email turfdecktrblshoot@gmail.com. Posting publicly to the board requires a GitHub account.
